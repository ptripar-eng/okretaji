# Slike rubrika Okretaji

Četiri izvorne AI ilustracije izrađene ugrađenim image_gen alatom 4. studenoga 2026. Nisu fotografije stvarnih modela vozila, stvarnog laboratorija niti određene lokacije. Bez preuzetih fotografija i bez ugrađenih logotipa. Web inačice: JPEG, 900 × 600 px. Izvornici i promptovi sačuvani u lokalnoj mapi Slike-rubrika.
